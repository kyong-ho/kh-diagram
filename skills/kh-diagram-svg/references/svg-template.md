# 틀로 그리기: 클래스와 부품 조각

프로그램을 돌리지 않고, 색·선·글꼴·프레임이 미리 들어 있는 SVG 틀(`assets/svg-template/frame-S.svg`)을 복사해 **좌표와 글만** 적습니다. 모양 값은 틀의 `<style>`이 정하므로 누가 그려도 같은 디자인이 나옵니다. 다 그린 예시는 `references/svg-template-examples/`에 있습니다. 그림 규칙은 `style.md`, 전체 순서는 SKILL.md에 있습니다.

## 순서

1. 틀을 출력 폴더에 그림 이름으로 복사한다: `assets/svg-template/frame-S.svg` → `images/4-01.svg`.
2. 틀 맨 위 주석이 말하는 세 곳을 고친다.
   - `aria-label`과 `class="title"` 글: 그림 제목 문장(둘이 같다).
   - 표제란: `과정 이름`, `그림 1-1` → `그림 4-1`.
   - 높이 H(420~680): `[H]` 주석이 붙은 네 곳. svg의 `viewBox` 넷째 값과 `height`, 배경 rect의 `height`(H), 테두리 rect의 `height`(H-16), 표제란 묶음의 `translate(0,H)`.
3. 맨 아래 "그림 내용" 자리에 부품 조각(아래)을 적는다. 비슷한 예시 그림(`svg-template-examples/`)이 있으면 그 좌표 간격을 그대로 가져온다.
4. 브라우저로 열어 확인한다(맨 아래 "확인").

**고치지 않는 것:** `<style>`, `<defs>`, 배경·테두리·제목 위치, 표제란, 저작권 줄. 그림 내용에는 색(hex)·`style=`·`font-size=`·`opacity`를 적지 않고 클래스만 쓴다. 클래스로 안 되는 모양이 필요하면 멈추고 사용자에게 묻는다.

## 클래스

| 대상 | 클래스 |
|---|---|
| 글자 크기 | `f10` `f105` `f11` `f12` `f125`(12.5) `f13` `f135` `f14` `f145` `f15` `f155` `f16` `f17` `f18` `f23`. 없으면 15 |
| 글자 색 | `ink` 남색, `grn` 초록, `red` 빨강, `mute` 회색, `wht` 흰색. 없으면 본문 글자색(G) |
| 굵기·정렬 | `b` 굵게(700). `mid` 가운데, `end` 오른쪽 맞춤. 없으면 400, 왼쪽 |
| 글자 묶음 | `h` 상자 제목(16 굵게), `sub` 보조 설명(12.5 회색), `point` 맨 아래 요점 줄(13.5 회색). `title`·`tb`·`copy`는 프레임 전용 |
| 상자 | `box` 흰 면+남색 테. `area` 옅은 남색 면(영역·받는 것·입력), `area-g` 옅은 초록 면+초록 테(원격·결과), `area-a` 옅은 노랑 면(주의할 점), `area-r` 옅은 빨강 면+빨강 테 |
| 상자 고쳐 쓰기 | 면: `tint` `grnt` `redt` `ambt` `clear`(면 없음). 테: `k-ink` `k-grn` `k-red` `k-line` `k-g` `k-mute`. 점선: `dash`(5 4), 묶어 강조하는 테두리 `dash6`(6 5) |
| 화면 그림 | `win` 창(rx 8), `panel` 단계 칸(rx 10), `field` 입력 칸, `btn` 파란 기본 버튼(rx 5), `btn2` 흰 버튼 |
| 선 | `sep` 옅은 구분선 |
| 화살표 | `arr-i` 남색, `arr-g` 초록, `arr-r` 빨강, `arr-m` 회색. 돌아오는 결과는 `dash`를 더한다 |
| 번호 원 | `<g class="num">`(남색), `num g` 초록, `num r` 빨강 |

모서리(`rx`)는 클래스가 아니라 요소에 적는다: 상자·영역 `4`, 창 `8`, 단계 칸 `10`, 버튼 `5`.

## 부품 조각

자주 쓰는 모양의 조각입니다. `x`, `y`, `w`, `h`만 바꿔 씁니다.

**제목·설명이 있는 상자**. 글은 `x+16`, 제목 `y+h/2-3`, 설명 `y+h/2+17`. 설명이 없으면 제목만 `y+h/2+6`.

```svg
<rect class="box" x="242" y="170" width="160" height="62" rx="4"/>
<text class="h" x="258" y="198">파일들</text>
<text class="sub" x="258" y="218">README.md 등</text>
```

**영역**(옅은 면 + 이름). 이름은 `x+18`, `y+26`, 15 굵게. 초록 영역은 `area-g`와 `grn`.

```svg
<rect class="area" x="200" y="84" width="430" height="380" rx="4"/>
<text class="f15 ink b" x="218" y="110">내 PC</text>
```

**화살표와 이름**. 가로 화살표의 이름은 선보다 10 위나 22~24 아래, 세로 화살표는 옆(선 x+10)에 둔다. 화살촉은 선 끝에 붙으니 상자 테두리에서 1~2 떨어진 곳에서 끝낸다.

```svg
<path class="arr-g" d="M606,190 L712,190"/>
<text class="f135 grn b mid" x="659" y="180">푸시</text>
<path class="arr-i dash" d="M712,222 L608,222"/>
```

**번호 원**. 숫자는 `cy+5`. 화면 위 누를 곳은 빨강에 흰 테를 먼저 깐다.

```svg
<g class="num"><circle cx="56" cy="136" r="13"/><text x="56" y="141">1</text></g>
<g class="num r"><circle class="halo" cx="300" cy="200" r="15"/><circle cx="300" cy="200" r="13"/><text x="300" y="205">1</text></g>
```

**번호 설명(범례)**. 오른쪽 세로: 번호 `(x, y)`, 제목 `(x+26, y+6)` 15 굵게, 설명 `(x+26, y+30)` 12.5 회색, 다음 줄은 19 아래, 다음 항목은 92 아래. 아래 가로: 칸 폭 293, 번호 `(cx+12, y)`, 제목 `(cx+34, y+5)` 13.5 굵게, 설명 `(cx+34, y+26)` 12 회색.

```svg
<g class="num r"><circle cx="610" cy="118" r="13"/><text x="610" y="123">1</text></g>
<text class="f15 b" x="636" y="124">Add file</text>
<text class="sub" x="636" y="148">파일을 올리는 메뉴</text>
```

**단계 칸**. 번호 `(x+24, y+26)`, 제목 `(x+46, y+32)` 14.5 굵게.

```svg
<rect class="panel" x="40" y="90" width="280" height="300" rx="10"/>
<g class="num"><circle cx="64" cy="116" r="13"/><text x="64" y="121">1</text></g>
<text class="f145 b" x="86" y="122">폴더 만들기</text>
```

**칸 안 여러 줄**. 제목 아래 28, 그다음 줄 간격 22(예시 `work-procedure-2-01.svg`의 ④ 단계).

**화면 그림 아래 안내**.

```svg
<text class="sub" x="40" y="500">실제 화면을 단순하게 그린 그림입니다. 버전에 따라 모양과 위치가 조금 다를 수 있습니다.</text>
```

**맨 아래 요점 줄**. 마지막 줄을 `y = H-60 ~ H-54`에 둔다. 두 줄이면 24 간격.

```svg
<text class="point" x="40" y="464">같은 저장소가 두 곳에 있고, 푸시와 풀로 서로 맞춥니다.</text>
```

## 좌표 요령

- 그림 폭은 960이다. 내용은 왼쪽 36~40부터 오른쪽 920까지, 위는 제목 아래 84~110부터 쓴다.
- 같은 칸을 가로로 늘어놓을 때는 폭과 간격을 정해 계산한다. 예: 6칸은 폭 132, 150 간격(`x = 36 + 150×i`), 2칸은 폭 420, 460 간격, 3칸은 폭 230·320·230에 칸 사이 50.
- 글자 폭은 직접 어림한다. 한글 한 글자는 글자 크기의 약 0.86배, 영문 소문자·숫자는 약 0.5배다(16 굵게 한글 10자 ≈ 138). 상자 폭은 가장 긴 줄보다 32 이상 넓게 잡는다. Windows의 맑은 고딕은 조금 더 넓을 수 있으니 여유를 둔다.
- 자동 줄바꿈이 없다. 긴 문장은 `<text>`를 두 개로 나누고 19~24 아래에 둔다. 연속 공백은 한 칸으로 보인다.
- 표제란은 오른쪽 아래 `x 682~952`, `y H-38~H-8`, 저작권 줄은 왼쪽 `y H-17`에 있다. 그 위를 덮지 않는다. 모자라면 높이를 늘린다(680까지).
- 글자 `&`, `<`는 `&amp;`, `&lt;`로 적는다.

## 확인

Node나 검사 프로그램 없이 브라우저로 본다. SVG 파일을 Edge·Chrome 창에 끌어다 놓거나, AI에게 "그림을 브라우저로 열어 줘"라고 부탁한다. 아래를 하나씩 본다.

1. 글자가 상자·테두리 밖으로 넘치지 않는가
2. 글자끼리 겹치지 않는가
3. 선·화살표가 글자를 지나가지 않는가
4. 아래 글이 표제란·저작권 줄을 덮지 않는가
5. 번호 원과 범례 번호가 맞는가, 그림이 한 가지를 말하는가

열리지 않거나 아무것도 안 보이면 `<style>`·`<defs>`를 지웠거나 태그를 닫지 않은 것이다. 틀에서 다시 복사해 내용만 옮긴다.

원고에는 다른 그림처럼 `![대체 텍스트](images/4-01.svg)`로 넣는다. SVG 코드를 HTML 본문에 직접 붙이지 않는다(틀의 `<style>`이 페이지 글자에도 번진다).
