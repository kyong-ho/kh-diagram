# 본문 그림 스타일

교육 자료·문서의 본문 그림(SVG 도해)을 늘 같은 모양으로 만들기 위한 규칙입니다. AI팀 리서치·학습 사이트(ai-lab)의 교육 가이드와 리서치 글 그림에서 뽑았습니다. kh-diagram 스킬로 그린 그림과 같은 디자인이 나옵니다.

## 그림

그림은 SVG 틀(`assets/svg-template/frame-S.svg`)을 복사해 좌표와 글만 적어 만듭니다. 색·선·글꼴·프레임은 틀의 `<style>`과 `<defs>`가 정하므로 그림 내용에는 클래스만 씁니다. 프로그램을 설치하거나 실행하지 않습니다.

### 프레임

도면형 하나만 씁니다. 직각 테두리, 왼쪽 위 제목, 오른쪽 아래 표제란(과정 이름, 그림 번호), 왼쪽 아래 저작권 줄. 폭 960, 높이는 내용에 맞춰 420~680. 화면 설명, 구조, 흐름, 칸 나열, 판단 순서를 모두 이 프레임에 그립니다.

### 규칙

- **색:** 틀의 클래스만 씁니다. 남색(`ink`, `box`, `arr-i`)이 기본이고, 초록(`grn`, `area-g`, `arr-g`)은 원격·완료·결과·권장, 빨강(`red`, `arr-r`, `num r`)은 주의·삭제·번호 표시, 회색(`mute`, `sub`, `point`)은 보조 설명입니다. 옅은 면(`area`, `area-g`, `area-a`, `area-r`)은 영역을 구분할 때만 씁니다(받는 것·입력은 `area`, 결과는 `area-g`, 주의할 점은 `area-a`). 문서·사이트의 디자인 색과는 별개인 그림 전용 색입니다.
- **글자:** 제목 23(틀에 있음), 상자 제목 15~17, 라벨 13~14, 보조 설명 12~12.5, 맨 아래 요점 줄 13.5 회색. 굵기는 보통과 굵게(`b`)만 씁니다. 자동 줄바꿈이 없으므로 긴 문장은 직접 두 줄로 나눕니다.
- **선:** 테두리 1.5, 화살표 2(틀에 있음). 모서리는 상자 4, 창 8, 단계 칸 10. 그라디언트, 그림자, 투명도, 이모지는 쓰지 않습니다.
- **화면 그림:** 실제 화면을 캡처하지 않고 단순하게 다시 그립니다. 누를 곳에 빨간 번호 원을 얹고, 같은 번호의 설명을 오른쪽이나 아래에 둡니다. 화면 문구는 실제 표기 그대로 적습니다. 그림 아래에 "실제 화면을 단순하게 그린 그림입니다…" 안내를 둡니다.
- **지어내지 않기:** 받은 내용에 없는 담당·날짜·설명은 넣지 않고 회색으로 `(확인 필요)`라고 적습니다.
- **한 그림에 한 가지:** 그림 제목은 그 그림이 말하려는 것을 문장으로 씁니다. 맨 아래에 회색 한두 줄로 요점을 다시 적을 수 있습니다.
- **파일 이름:** `장-순번.svg`(`6-02.svg`). 운영체제별 그림은 `4-01-win.svg`·`4-01-mac.svg`. 표제란의 그림 번호는 `그림 6-2`입니다. 장이 없는 글은 `<글 주소>-1.svg`, 표제란 `그림 1`. PNG는 올리지 않습니다.

### 원고에 넣기

- `![대체 텍스트](images/6-02.svg)`를 단독 문단으로 둡니다. 절 제목 바로 아래, 번호 단계 앞에 놓습니다. SVG 코드를 HTML 본문에 직접 붙이지 않습니다.
- 대체 텍스트는 그림에서 봐야 할 것을 한 문장으로 씁니다. 구조·흐름 그림은 "…을 보여 주는 그림"으로 끝내고, 화면 그림은 `화면 이름: 보이는 요소 나열`로 씁니다. 캡션은 따로 달지 않습니다.
- 실습이 있는 장에는 개념 그림 하나와 실습 화면 그림을 합쳐 2~5개를 둡니다.
