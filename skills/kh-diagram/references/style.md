# 본문 그림 스타일

교육 자료·문서의 본문 그림(SVG 도해)을 늘 같은 모양으로 만들기 위한 규칙입니다. AI팀 리서치·학습 사이트(ai-lab)의 교육 가이드(GitHub 기초 가이드 등)와 리서치 글 그림에서 뽑았습니다. 규칙으로 판단이 서지 않으면 스킬의 `references/examples/`에서 같은 종류의 그림을 찾아 맞춥니다.

## 그림

그림은 손으로 쓰지 않고 프로젝트의 `scripts/figures/`에 둔 Python 스크립트로 만듭니다. 공용 모듈 `figlib.py`가 색·프레임·부품을 고정하므로 스크립트에는 구도와 글만 적습니다.

```text
scripts/figures/figlib.py            공용 모듈(색, 프레임 2종, 부품)
scripts/figures/build.py             한 과정의 그림을 모두 다시 만듦
scripts/figures/check.mjs            브라우저로 그려 PNG를 남기고 글자 넘침·겹침을 찾음
scripts/figures/<과정>/course.py     표제란 이름, 출력 폴더, 그 과정 전용 부품
scripts/figures/<과정>/ch06_07.py    장별 그림

```

```text
python3 scripts/figures/build.py <과정>
```

Python 3 기본 설치만 있으면 됩니다. 내용이 바뀐 그림만 `course.py`가 정한 폴더에 다시 쓰고 그 파일 이름을 출력합니다.

Python이 없는 PC에서는 같은 색·선·글꼴·프레임을 담은 SVG 틀(`assets/svg-template/frame-S.svg`)을 복사해 좌표와 글만 적습니다. 순서와 부품 조각은 `svg-template.md`에 있습니다. 아래 규칙은 두 방식에 똑같이 적용됩니다.

글자 폭은 스크립트가 계산하지 않습니다. 만든 그림은 아래 명령으로 브라우저에 그려 PNG를 남기고, 테두리 밖 글자·글자끼리 겹침·상자 경계에 걸친 글자·글자를 지나는 선을 찾습니다. 찾은 것은 후보이므로 PNG를 열어 실제로 넘치거나 겹친 것만 고칩니다.

```text
node scripts/figures/check.mjs figures-out/<과정>
```

### 프레임

| 프레임 | 쓰는 곳 | 모양 |
|---|---|---|
| `P` 개념 만화형 | 비유로 흐름을 훑는 개념 장(보통 1장) | 둥근 테두리, 왼쪽 위 번호 원, 아래 띠에 제목과 한 줄 설명. 960×480 고정 |
| `S` 도면형 | 그 밖의 모든 그림(화면 설명, 구조, 흐름, 판단 순서) | 직각 테두리, 왼쪽 위 제목, 오른쪽 아래 표제란(과정 이름, 그림 번호). 폭 960, 높이는 내용에 맞춰 420~680 |

### 규칙

- **색:** `figlib.py`의 상수만 씁니다. 남색 `INK`가 기본이고, 초록 `GRN`은 원격·완료·권장, 빨강 `RED`는 주의·삭제·번호 표시, 회색 `MUTE`는 보조 설명입니다. 옅은 면(`TINT`, `GRNT`, `REDT`, `AMBT`)은 영역을 구분할 때만 씁니다. 문서·사이트의 디자인 색과는 별개인 그림 전용 색이며, 그림 안에서만 씁니다.
- **글자:** 제목 23, 상자 제목 15~17, 라벨 13~14, 보조 설명 12~12.5. 굵기는 400과 700만 씁니다. 글자는 한 줄씩 넣으며 자동 줄바꿈이 없으므로, 긴 문장은 직접 두 줄로 나눕니다.
- **선:** 테두리 1.5, 화살표 2(만화형 3.5). 모서리는 상자 4, 창 8, 말풍선 16입니다. 그라디언트, 그림자, 투명도는 쓰지 않습니다.
- **화면 그림:** 실제 화면을 캡처하지 않고 단순하게 다시 그립니다. 누를 곳에 빨간 번호 원(`callout`)을 얹고, 같은 번호의 설명을 오른쪽(`legend`)이나 아래(`legend_row`)에 둡니다. 화면 문구는 실제 표기 그대로 적습니다.
- **한 그림에 한 가지:** 그림 제목은 그 그림이 말하려는 것을 문장으로 씁니다. 맨 아래에 회색 한두 줄로 요점을 다시 적을 수 있습니다.
- **파일 이름:** `장-순번.svg`(`6-02.svg`). 운영체제별 그림은 `4-01-win.svg`·`4-01-mac.svg`. 표제란의 그림 번호는 `그림 6-2`입니다. PNG는 올리지 않습니다.
- 새 과정에서 여러 그림에 반복되는 화면(그 프로그램의 창 틀 등)은 `course.py`에 부품으로 만듭니다(스킬의 `references/examples/github-basics/course.py`의 `desktop()` 참고). 다른 과정에서도 쓸 부품이면 `figlib.py`에 둡니다.

### 원고에 넣기

- `![대체 텍스트](images/6-02.svg)`를 단독 문단으로 둡니다. 절 제목 바로 아래, 번호 단계 앞에 놓습니다.
- 대체 텍스트는 그림에서 봐야 할 것을 한 문장으로 씁니다. 구조·흐름 그림은 "…을 보여 주는 그림"으로 끝내고, 화면 그림은 `화면 이름: 보이는 요소 나열`로 씁니다. 캡션은 따로 달지 않습니다.
- 실습이 있는 장에는 개념 그림 하나와 실습 화면 그림을 합쳐 2~5개를 둡니다.
